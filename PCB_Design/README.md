# KiCad PCB Design

This directory contains the editable KiCad project files for the Air Mouse PCB.

## Included files

- `airmouse_embedded.kicad_pro` - KiCad project settings
- `airmouse_embedded.kicad_sch` - circuit schematic
- `airmouse_embedded.kicad_pcb` - PCB layout
- `airmouse_embedded.net` - exported netlist

Open `airmouse_embedded.kicad_pro` in KiCad to work with the project.

Temporary lock files (`*.lck`), local project state (`*.kicad_prl`), and the local footprint information cache are intentionally excluded. KiCad can regenerate these local files when the project is opened.
